# Fitness App

A 5-day women's **Tone & Sculpt** split tracker with an animated, rigged 3D model that demonstrates every exercise.

- Day tiles with progress rings, filter by day or exercise name
- Checkmarks to track the week (saved in the browser)
- Warm-up notes and a beginner form cue for every exercise
- Realistic rigged model: hands grip dumbbells, bars and cables; controlled rep tempo; breathing and idle movement

Open `index.html` in a browser (it loads `model.js`, so keep both files together), or enable GitHub Pages on this repo.

`mens-split.html` is the companion 5-day Push / Pull / Legs / Upper / Lower tracker.

Built with [three.js](https://threejs.org) r147.
